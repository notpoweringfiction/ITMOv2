# Notify Mini
Учебный сервис подписки. Подписчики хранятся в памяти процесса.

В `service.py`:

- `subscribe(name)` — добавляет непустое имя (с обрезкой пробелов) в множество, не создаёт дубликатов.
- `unsubscribe(name)` — удаляет подписчика, возвращает `{"unsubscribed": True}` если был удалён, `{"unsubscribed": False}` если имени не было. Пустое имя — `ValueError`.
- `list_subscribers(sorted_=True)` — возвращает список подписчиков; по умолчанию отсортированный для детерминированных тестов.

Проверка: `make test`.
Зависимости: стандартная библиотека Python 3.10+.
