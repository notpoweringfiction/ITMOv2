# Нагрузочные проверки

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |
|---|---|---|---|---|
| Большие diff (в пределах лимита) | 1–5 MiB, rps=${RPS_LARGE:=2}, duration=5m | p95 ≤ ${P95_LIMIT_SEC:=4}s; p99 ≤ ${P99_LIMIT_SEC:=8}s; 5xx ≤ ${ERRORS_MAX:=0}; ΔRAM ≤ ${MEM_DELTA_MB:=200}MiB; CPU ≤ ${CPU_PCT:=80}% | Время ответа (p95/p99), коды 2xx/5xx, потребление CPU/RAM | Связано с рисками 2 и 5 из prompt_P1_02 |
| Дифф больше лимита (отказоустойчивость) | размер > ${MAX_DIFF_BYTES:=1048576} байт, rps=1, duration=1m | ≥99% ответов 413 ≤ ${P95_413_SEC:=1}s; 5xx=0 | Доля/время 413, отсутствие 5xx | Связано с риском 5 из prompt_P1_02 |
| Базовая нагрузка малыми diff | 1–5 KiB, rps=${RPS_SMALL:=20}, duration=10m | p95 ≤ ${SMALL_P95_LIMIT_MS:=500}ms; error rate ≤ ${SMALL_ERR_RATE:=0.5}% | Время ответа, доля ошибок | Связано с базовыми проверками из prompt_P1_02 |

Плейсхолдеры допускают переопределение через переменные окружения в инструментах нагрузки; значения по умолчанию указаны после `:=`.

Если нагрузочное тестирование пока не требуется, обоснуйте это и назовите условие, после которого оно понадобится.

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): «конкретизация порогов с плейсхолдерами и значениями по умолчанию; добавление независимых измеримых критериев» (см. practices/practice_02/prompts.md)
- Что проверили и исправили сами: заменили N/X на именованные плейсхолдеры с дефолтами; добавили независимые метрики (p95/p99, error rate, CPU/RAM), сценарий на 413 и базовую нагрузку
