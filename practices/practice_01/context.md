## Context Pack для первого рабочего сценария

### Факты и правила

- Обязательный вход: строка diff
- Разрешённый источник для анализа: только TRAINING_PR.diff
- Анализ строго по diff, без домыслов и внешних файлов

### Формат входа и результата

- Вход: JSON с полем diff: string
- Результат: JSON {"comment": string}

### Ограничения и запрещённые действия

- Запрещено: approve, merge, edit (см. prompt_P1_02 PROMPT)
- Остановиться и запросить человека при отсутствии обязательного входа

### Хороший пример


- POST /api/reviews с корректным JSON {"diff": "..."}; ожидание 200 и поля comment

### Плохой пример


- Запросы без поля diff; попытки анализировать файлы вне TRAINING_PR.diff

### Что пока неизвестно

- Целевая версия Python (влияет на аннотации типов)
- Политика аутентификации/лимитирования для /api/reviews
- Максимальный допустимый размер diff и поведение при превышении
