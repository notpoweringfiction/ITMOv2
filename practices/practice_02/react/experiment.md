# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: найти самый ненадёжный артефакт среди документов Практики 1 по evidence из prompt_P1_01/prompt_P1_02 и минимально усилить его.
- Доступные входы: practices/practice_01/*.md, prompt_P1_01.md, prompt_P1_02.md.
- Разрешённые действия: анализ файлов, правки markdown-артефактов Практики 1, заполнение этого отчёта.
- Запрещённые действия: менять внешний код за пределами артефактов Практики 1; придумывать несуществующие результаты.
- Максимальное число шагов: 4.
- Условие остановки и вопроса человеку: если отсутствует однозначный выбор артефакта или требуются продуктовые решения.
